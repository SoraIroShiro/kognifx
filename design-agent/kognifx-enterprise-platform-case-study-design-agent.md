# Design Agent Task --- Kognifx Enterprise Platform Case Study Page

## Objective

Create a new case study page for Kognifx website showcasing a flagship
enterprise software project.

The page should position Kognifx as an AI-first software house and
technology partner that builds custom enterprise platforms based on real
business processes.

Primary angle: "Enterprise Platform Development --- Mengubah Proses
Bisnis Kompleks Menjadi Sistem Digital Terintegrasi"

Do NOT position this as only a leadership/community application or a
dashboard project.

The Maxwell Leadership Indonesia project is the context/example, but the
main value proposition is Kognifx's capability in building complex
enterprise platforms.

------------------------------------------------------------------------

# Page Goals

The page should:

-   Build trust for B2B visitors
-   Demonstrate capability in handling complex workflows
-   Support SEO around:
    -   enterprise software development
    -   custom enterprise software
    -   business management system
    -   custom platform development
    -   software house Indonesia

The page should follow the existing Kognifx design system and UI
patterns.

Reuse: - typography - spacing - component style - card style - CTA
style - responsive behavior - animation style (if existing)

Do not introduce a completely new visual language.

------------------------------------------------------------------------

# 3. Business Challenge

Focus on business problems, not features.

Content direction:

Organizations with growing operations often face challenges:

-   Data spread across different tools
-   Multiple teams managing different processes
-   Difficulty tracking member/customer lifecycle
-   Complex event access management
-   Lack of centralized operational visibility

Use cards or visual blocks.

------------------------------------------------------------------------

# 5. Platform Capabilities

Follow Kognifx brand voice:

-   Clear
-   Practical
-   Human
-   Business-focused

leverage - holistic
