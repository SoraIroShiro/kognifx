# Kognifx — Phase 2 Expanded Keyword Universe & Mapping

## Patch ID
`phase-2-expanded-keyword-universe`

## Core Principle

Maximize the number of **relevant search concepts Kognifx can cover across the site**, not the number of keywords stuffed into one page.

Google should learn Kognifx through a broad, coherent topical architecture: commercial pages, supporting informational content, internal links, entity signals, and real use cases.

Do **not** use `<meta name="keywords">`, hidden keyword blocks, comma-separated keyword dumps, doorway pages, or near-duplicate pages.

This task contains **531+ curated seed phrases** across 28 clusters. They are candidate concepts, not claimed search-volume data.

Do not invent search volume, CPC, keyword difficulty, traffic, or ranking probability. Mark those as `UNKNOWN` unless real data is supplied from GSC/Keyword Planner/another verified source.

## Classification Required for Every Keyword

For each candidate, classify:

- Language: ID / EN
- Intent: Brand / Commercial / Transactional / Informational / Comparison / Problem-aware / Navigational
- Funnel: TOFU / MOFU / BOFU
- Cluster
- Parent topic
- Proposed owning URL
- Page type: homepage / solution hub / solution detail / case study / article / FAQ-supporting section
- Priority: P0 / P1 / P2 / P3
- Status: EXISTING PAGE / NEW PAGE LATER / SUPPORTING TERM / DO NOT TARGET SEPARATELY
- Evidence: CURRENT SERP LANGUAGE / SEMANTIC CANDIDATE / NEEDS GSC VALIDATION

## Cannibalization Rules

1. One dominant intent should have one primary owning page.
2. Phrase variants should usually stay on the same page.
3. Do not create one page for every acronym/product name.
4. AI Agent remains inside AI Automation initially unless intent divergence is demonstrated.
5. CRM/HRIS/WMS/etc may become pages later, but only when content depth and commercial importance justify separation.
6. Homepage remains broad brand positioning, not a keyword dump.
7. `/id/solusi` remains a hub; child pages own specific commercial intents.
8. Informational articles support commercial pages through internal links.
